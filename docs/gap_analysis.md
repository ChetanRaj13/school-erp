# PaperBuddy Gap Analysis

Source: live audit of paperbuddy.in's public demo (48 screens across Admin,
Teacher, and Student/Parent apps), conducted directly against the product,
not assumed. AGENTS.md hard rule: do not invent or extrapolate new gap
figures beyond what's documented here — extend this file if a fresh audit
is done.

## Key gaps found
1. No online payment gateway — QR-at-desk + manual cash/bank logging only
2. No fee financing / EMI option for parents
3. No expense, payroll, or vendor-payment module (revenue-only dashboards)
4. No admissions CRM (enquiry -> application -> enrolment)
5. No accounting-grade export (GST / Tally / double-entry ledger)
6. No staff leave <-> payroll linkage (student leave has a full workflow, staff doesn't)
7. AI-generated content (quizzes, papers, report comments) has no visible
   teacher-approval/plagiarism-check gate before reaching students/parents
8. No visitor management / campus safety module
9. Communication is one-way broadcast only — no PTM scheduling
10. Library, hostel, canteen, asset/inventory modules referenced by icon but not built
11. Heavy assumption of constant high-bandwidth connectivity (no offline mode)
12. No visible DPDP Act 2023–aligned consent dashboard for AI-driven data use
13. No multi-branch/franchise dashboard for coaching chains
